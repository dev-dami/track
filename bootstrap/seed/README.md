# bootstrap/seed

GENERATED by `scripts/update_seed.sh`. Do not edit by hand.

- `trackc.c` is the C that `trackc` emits for `compiler/src/main.trk` at its
  fixed point.
- `trackc.rt.c` is the C runtime that `trackc` writes beside that C. It is a
  copy of `runtime/track_runtime.c`.

`scripts/bootstrap.sh` compiles both files with plain `cc` to get stage1
`trackc`. No Rust is needed. stage1 then rebuilds the compiler from
`compiler/src/`. `scripts/update_seed.sh --check` fails when these files no
longer match what the current sources produce. Rerun `scripts/update_seed.sh`
after any change to `compiler/src/`, `compiler/rt/` or `runtime/`.
