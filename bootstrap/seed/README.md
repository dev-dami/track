# bootstrap/seed

GENERATED by `scripts/update_seed.sh`. Do not edit by hand.

`trackc` is the static x86-64 Linux ELF that `trackc` builds from
`compiler/src/main.trk` at its fixed point. It links no libc and needs no
loader.

`scripts/bootstrap.sh` runs it to build stage1 from `compiler/src/`, then
stage2 and stage3, and requires stage2 = stage3 byte for byte. No C compiler,
assembler or linker is used at any step. `scripts/update_seed.sh --check` fails
when the seed no longer matches what the current sources produce. Rerun
`scripts/update_seed.sh` after any change to `compiler/src/` or `compiler/rt/`.
